# Umeda Atlas · 大阪梅田立体地图

JR 大阪站局部交互样板，使用 TypeScript + Three.js。固定正等轴测方向，轨道在画面中由左下延伸至右上，验证建筑拆解质感、楼层阅读与简单跨层路线。

**当前布局、设施位置、站台号与路线均为示意，不能用于现场导航。** 参考资料用于理解结构和造型，本轮未完成按比例描图、地理校准或设施逐项核验；不包含完整车站及站间连接。

## 本地运行

需要 Node.js 24 或以上。

```sh
npm install
npm run dev
```

手动打开 <http://127.0.0.1:5173>。修改 `src/` 后自动重新构建，刷新页面查看；目前不自动刷新浏览器。

Windows PowerShell 若阻止执行 `npm.ps1`，将命令中的 `npm` 换成 `npm.cmd`。

## VS Code 入口

安装依赖后，在“运行和调试”选择 **JR 大阪站 · 启动服务**，按 F5。该配置仅启动服务，不打开浏览器；手动访问上面的地址即可。停止调试会停止此服务。

另有 **JR 大阪站 · 本地预览** 配置，可由用户主动选择，让 VS Code 启动 Chrome。该配置的后台开发任务需要通过“终止任务”或终端 Ctrl+C 停止。两个入口均使用 5173 端口，不要同时启动。

`Ctrl+Shift+B` 构建网页；“运行任务”中还提供类型检查和测试入口。

## 交互范围

- 三层局部结构：1F 中央站厅、2F 站台、3F 南北连络桥。
- 倾斜大屋顶、采光带、简化桁架、平行站台与雨棚。
- 楼层聚焦、分层展开、屋顶显隐、缩放、平移、复位。
- 常驻南北方位示意：北在左上、南在右下；样板坐标暂按 X 向东、Z 向南约定，尚未地理校准。
- 点选闸机、售票处、扶梯、直梯，或使用右侧设施列表。
- 一条示意路线：中央口 → 闸机 → 上行扶梯 → 站台，展示闸内外和跨层关系。
- 手机布局与双指缩放已编写，尚未在浏览器或真机验证。

## 检查与交付

```sh
npm run typecheck
npm test
npm run build
```

入口为 `dist/index.html`，通过相对路径加载同目录的 `app.js` 与 `styles.css`；当前地图数据随 JS 打包，后续模型、图片等可拆为独立资源。复制或部署时保留整个 `dist/`，无需将所有资源内嵌 HTML。当前无 CDN、远程字体或外部地图请求，保留 Three.js 许可证。主要通过 HTTP 访问，`file://` 打开兼容性仍需浏览器验证。`dist/` 不纳入 Git。

本轮已通过严格类型检查、构建及导航规则测试；未进行浏览器自动操作或视觉验收。后续先人工查看屋顶比例、展开遮挡、移动端可读性和路线显示，再推进精确地图数据。

## 源码边界

```text
src/
  domain/map/           领域类型，无渲染依赖
  domain/navigation/    路径查找与通行规则
  application/          地图会话与路线用例
  infrastructure/       局部样板数据
  presentation/         Three.js 场景、设施选择与几何表现
  utils/                通用 DOM 工具
  main.ts               应用组装与事件绑定
  index.html            页面模板
  styles.css            界面样式
tests/                  导航规则测试
scripts/                TypeScript 构建及本地服务
dist/                   网页产物（忽略）
docs/                   方案与参考资料评估
references/             原始资料（保留）
```

遵循 DDD 的领域与技术依赖边界，不引入暂时用不到的仓储、事件总线或复杂框架。展开后的视觉高度只影响渲染，不参与路径代价计算。
