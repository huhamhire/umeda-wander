# 旧版示意坐标归档

这里保留重构前的地区总图、商业轮廓、公共连接和轨道生成器，供布局对照及既有回归测试使用，不是 H5 的第二个入口。

- 当前页面：`src/infrastructure/district/geographic-map.ts`。
- 当前车站：`src/infrastructure/stations/<station-id>/`，旧图也复用其中的原始局部布局，不能整体删除现役站点数据。
- 归档总图：`infrastructure/umeda-map.ts`；旧车站登记、地区连接、商业模型及数据导出随依赖链归档。
- 原根目录十个站点兼容转发已删除，调用方直接导入实际模块；这些转发不包含独立布局。
- `src/` 不得导入本目录。旧测试可继续导入，`tsconfig.json` 显式包含归档，避免漏掉类型错误。离线旧坐标校准脚本仍可运行。

新位置、公共网和轨道调整只修改现役模块。归档内容仅在对照／回归需要时维护，不扩展新功能。原始资料继续保存在 references，不随本次清理移动或删除。
