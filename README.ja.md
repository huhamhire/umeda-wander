# UMEDA · 駅めぐり

[English](./README.md) · [简体中文](./README.zh-CN.md) · 日本語

「UMEDA · 駅めぐり」は、大阪・梅田の駅周辺を探索できるインタラクティブな立体地図です。各駅のフロア、ホーム、改札を一つの地図で確認でき、地下通路や2階の連絡デッキが駅と周辺の建物をどう結んでいるかを把握できます。

対象は、JR大阪駅、阪急大阪梅田駅、御堂筋線梅田駅、阪神大阪梅田駅、谷町線東梅田駅、四つ橋線西梅田駅、JR北新地駅の7駅です。

**形状、設備の位置、経路は模式的な表現です。現地での経路案内には使用できません。**

## プロジェクトの背景

本プロジェクトは、作者が大阪・梅田に数日間滞在した経験をきっかけに始まりました。複数の鉄道事業者の駅が地下街、地上の出入口、2階の連絡デッキで結ばれ、その多層的な歩行者ネットワークは「梅田ダンジョン」とも呼ばれています。公開されている駅構内図や地理データをもとに、資料整理、空間のモデリング、インタラクティブな地図の開発にAIを活用する試みです。

> **駅周辺の沿革と参考資料**

> - 初代大阪駅は1874年に開業しました。1933年に現在の御堂筋線にあたる梅田〜心斎橋間が開通し、1939年に阪神梅田駅が地下へ移設されました。1963年に開業したウメダ地下センター（現・ホワイティうめだ）は、地下鉄の改札と周辺の百貨店やビルを結びました。阪急梅田駅は拡張工事を経て1973年に現在の場所で完成しました。[大阪ステーションシティの歴史](https://www.osakastationcity.com/about/gallery/develop.php) · [大阪市立図書館「近代・現代の大阪」](https://www.oml.city.osaka.lg.jp/page/1147.html) · [阪急阪神グループの沿革](https://www.hankyu-hanshin.co.jp/docs/5a3dc356c73b5a393bd52202f6320606d60a6fe2.pdf) · [阪急大阪梅田駅の沿革](https://www.hankyu-hanshin.co.jp/release/docs/dbc36f2ba7c005e19e021aab9cf0b947c4bf3802.pdf) · [大阪地下街の歩み](https://www.osaka-chikagai.jp/70th/history)

> - 大阪ステーションシティの周辺ガイドでは「梅田ダンジョン」という呼称が使われています。Jタウンネットが2019年に実施した迷宮のような駅を選ぶ読者投票では、大阪（梅田）が候補7駅の中で1位でした。[大阪駅周辺ガイド](https://media.osakastationcity.com/25942/) · [Jタウンネットの投票結果](https://j-town.net/2019/03/22277320.html?p=all)

## 地図の機能

- フロアを展開して、ホーム、改札、エスカレーター、階段、エレベーターを確認できます。駅、フロア、種類で設備を絞り込むか、地図から直接選択できます。
- 駅構内の徒歩ルートと、JR大阪駅からクロストを経由して阪神大阪梅田駅、西梅田駅、JR北新地駅へ向かう改札外の乗り換えルートを表示できます。阪急大阪梅田駅へは北側の2階連絡デッキを経由します。地点は検索または地図から選択でき、経由地は最大3か所です。[徒歩ルートの設計](./docs/design/walking-routes.md)
- 右上の「自由に探索」ボタンから自動ツアーを開始できます。表示言語は中国語、日本語、英語から選べます。ライト・ダークテーマの切り替えと消音にも対応しています。
- 画面が静止した後にURLをコピーすると、視点の位置、向き、傾き、拡大率、フロア、選択中の設備、表示中のルートを共有できます。横方向の表示範囲は、リンクを開く端末の画面比率によって変わります。

## ディレクトリ構成

```text
umeda-wander/
├── src/          # 地図と画面のソースコード
├── data/         # 派生データと地理情報の設定
├── references/   # 参照資料の原本と出典一覧
├── resource/     # README掲載用のスクリーンショット
├── scripts/      # 開発サーバー、ビルド、オフライン検証
├── tests/        # 分野別の回帰テスト
└── docs/         # 設計、開発、データ出典の文書
```

ソースコードの構成と地図データの組み立て処理については、[アーキテクチャ文書](./docs/development/architecture.md#项目结构)をご覧ください。
