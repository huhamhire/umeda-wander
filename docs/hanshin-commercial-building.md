# 阪神百货与 Twin Towers South 外观

## 对象与来源

阪神梅田本店的低层裙楼与大阪梅田 Twin Towers South 办公塔楼作为同一商业综合体维护，避免将百货和上部办公体量误画成两座独立建筑。

- [日本设计项目说明与外观照片](https://www.nihonsekkei.co.jp/projects/18825/)：低层百货使用曲面线形，上层办公采用规整外装；模型保留这种差异。
- [业主建筑概要](https://office.hankyu-hanshin.co.jp/twin-south/outline/)及[接入说明](https://office.hankyu-hanshin.co.jp/twin-south/access/)：核对用途与交通接入。
- [OSM way 502411898](https://www.openstreetmap.org/way/502411898) v19，读取日期 2026-11-16：保留 L 形综合体轮廓及东侧曲面转角，去掉近共线小节点。原始投影缓存于 `commercial-footprints.ts`，不把整块轮廓当成塔楼轮廓。
- 本地阪神构内图及梅田地下步行图：承接已有 B1 百货店口、南侧公共通路、南出口地面落台和二层步行连接。

## 示意拟合

`hanshin-commercial-building.ts` 独立维护建筑定义。原始 OSM 投影另平移 `(-24,+72)` 场景单位，使北面接到已放大的阪神南侧公共区域。此偏移是展示校准，不是实测位置。

裙楼高度取 11.5，东侧办公塔楼高度取 26，均为压缩显示值。塔楼使用东侧翼内的规整矩形范围与裙楼轮廓求交，保留西侧低矮裙楼，不将整个 L 形轮廓一直拉高。塔楼退台和高度依据参考图示意，不代表实测楼层或基准层测绘。

`hanshin-massing-details.ts` 绘制浅色立面竖片、百货裙楼的分段绿化色带、塔楼玻璃与竖框。绿化用低饱和块面表达，不增加街边树木或内部店铺。

## 步行连接与显示

建筑保留 B1、1F、2F 三个探索层，分别借用阪神独立 LevelId；不新增楼层导航项。`hanshin-commercial-links.ts` 衔接既有站体的地下和地面公共落台。旧二层延伸段保留兼容 ID `hanshin-dept-deck-reserve`，终点改为百货轮廓上的真实模型门户，不再悬空；南出口直梯支线同步接入该门户。

地下通路及已绘制目标的二层连桥继续不显示说明标签。总览中的裙楼外观和塔楼由“显示建筑轮廓”开关统一控制，选层隐藏外层造型，保留楼板、边界入口及既有公共通路。商业围墙和压顶按通路全宽避让。

验证包含塔楼位于裙楼内、东侧偏置、造型网格有限值、三层公共入口落在建筑边界、门户全宽不被墙体封住及地区公共通路不进入付费区。已检查两个离线观察方向，未操作浏览器。
