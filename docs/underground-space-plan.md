# 地下公共空间与车站外围约束

本文记录现有示意布局。后续空间迁移以 [空间重构 Roadmap](./spatial-refactor-roadmap.md) 为准：站体与建筑采用共同的近真实比例基准，设施可适度放大。下文的独立拟合比例与偏移是旧版实现记录，不作为新区域的设计原则；面状公共空间、孔洞与付费边界规则继续适用。

## 表达方式

地下公共空间与二层天桥分开维护。天桥保留沿中心线生成桥面的方式；地下采用连续的平面区域，可以有渐变宽度、扩宽路口、弧形边界及包围建筑区块的孔洞。连接骨架描述相邻关系和接口，不等同于最终楼板，也不直接作为现场导航路线。

本图采用以车站为重点的示意比例。车站内部可以适当放大，商业占位与连接距离可以压缩；不要求所有区域统一米制缩放。调整时优先保留站点相对方位、线路方向、公共／付费边界、接入口顺序和步行连通关系。不能为对齐外部轮廓而单独拖动站内扶梯、直梯或站台。

## 数据分工

- `StationMap.site` 可由单个车站模块独立提供分层外围区域。未提供时，`describeStationSite` 从本站楼板、站台范围生成外围集合与付费范围；它不是把整个站画成一个包围矩形，也不是现场开挖边界。修改站内布局后，派生范围同步更新。
- `stationPublicPortal` 沿外部连接方向找到本站公共区域边缘。原本落在公共区中心的骨架端点会收至边界；已重叠的公共落台不向外反向延长。商业接口仍使用建筑轮廓上的接入口。
- `south-walkway-plan.ts` 独立维护参考图黄色公共空间的区域边界和街区填充轮廓；`southern-underground.ts` 负责与各站外围并合、裁剪。骨架不再反过来决定地下街形状。
- `planUndergroundSpace` 合并可变宽度断面与面状节点，再减去占用区；保留所得多边形的孔洞。后续有清晰边界的资料可以直接增加区域轮廓，不必先拆成等宽通路。
- `PublicPassage.surfaceId` 表示已有公共面负责显示，原连线仅作为连接骨架保留。渲染时不再为这些骨架叠加长条楼板；围墙避让也以公共面为准。

同层商业地下楼板让出公共区域的真实多边形；相邻建筑占位则作为外部通路的避让范围。孔洞不会被重新填成楼板，地下也不添加天桥栏杆。公共面继续使用较深暖米色，区别于站台、付费区和商业区。

## 本次校准范围

以 `references/district/underground-walkway-map.pdf` 和 `references/district/elevated-walkways-2026.pdf` 的地下图为依据，先处理阪神、西梅田、北新地、东梅田之间的 DIAMOR／Whity 网络，包括第一生命弧形互通、圆形节点、中央与斜向街区路口及沿线建筑接口。

当前改用 `projectWalkwayReference`：以原 PDF 的历史渲染 `build/west-district-review/walkways-1.png` 为索引（该临时渲染现已清理，可由原 PDF 重建），裁剪 `(385,340,400,400)` 并放大 2.5 倍，在 1000px 平面手工简化主要黄色公共区域。阪神锚点 `(310,303)`、西梅田 `(116,640)`、北新地 `(480,885)`、东梅田 `(765,365)` 共用一个投影；保留 OSM 地理锚点，显示偏移单独记录。临时渲染不作为运行时资源发布。

源图并没有把第一生命西侧道路表达成直通 DIAMOR 东西主街的商场走廊，因此移除旧示意中的西向横穿长条。分别维护 Hilton／第一生命北侧弧形互通、中央纵街、DT／第4大楼斜街、东西 DIAMOR、曾根地下道和 T20 侧道路边缘。建筑占位随这些街区轮廓摆放，公共面减去其占用范围。阪神站内已过时的百货矩形占位移除，避免盖住圆形节点。

西梅田平面拟合比例改为轴向 0.65、横向 0.8；东梅田为轴向 0.4、横向 1，保留两侧站台横向轨道净距；北新地为轴向 1、横向 0.55，站台仍保留 7 单位宽度供设备显示。北新地轴向改为近东西向 93.4°，B1 北侧公共带对齐曾根地下道。三组站台扶梯水平跨度 26→12，电梯井与竖向层级继续保留，四桥线／东西线轨道相交时仍保持 8 单位的示意高差。

阪急百货及 Grand Building 按同一地理方向向西 15.4、向南 30.8 场景单位修正整个宿主，阪神百货显示拟合改为 `(-20,+36)`。建筑各楼层和上层轮廓随宿主移动。Whity 接口沿北侧公共厅、百货正面和 Grand Building 外侧道路转接，避免跨商场的斜向弦。北侧接驳末端仍需为放大的站体做局部适配，不能解释为实测边线。

不要求全图严格同比例；上述面和折点为人工简化与显示拟合，不声称描摹了工程开挖线。商业地下公共通路可进入同层商业楼板范围；楼板为通路让位，不代表绘制了完整商场室内图。初次展示及复位的分层展开为 0%。

北侧 LUCUA／Yodobashi／梅北地下部分尚未转换成该连续面，二层天桥也不套用地下生成规则。后续按同一顺序扩展：核对参考连接骨架和面边界 → 校准车站重点区域及外围范围 → 安置建筑占位 → 对齐公共接入口 → 检查占位避让与连通性。避免在没有资料支持时用最短直线自动补接两个区域。

## 检查

区域聚焦时，选中车站保持原色，其他站点和商业／地区空间灰化但保留模型。车站归属与楼层归属分开：商业模型不能仅因为挂在 JR 楼层组里就被当作 JR 本站；总览恢复原材质。区域灰化与下层灰化叠加，选中设施标记保留提示色。

南门大楼 50 扶梯与 T 直梯在大丸 2F 视图下原本仍通过可见性判断，但下部被 3F 公共楼板遮挡。本站 `jr-south-forecourt.ts` 为两处补了向前庭边缘开放的井口，统一进入楼板裁剪与围栏规划。开口为示意拟合尺寸，未宣称实测；不会用关闭模型深度检测的方式让它穿过实体楼板。

新增测试覆盖渐变断面、区域并合与保留孔洞、站点独立边界、边缘接口、公共面与站体不重叠、参考图关键节点、街区占位避让、Whity 三条连接的逐段公共面覆盖，以及商业楼板不覆盖公共面。另以离线平面图检查南侧组合，没有操作浏览器。

区域聚焦测试使用真实 Three.js 材质与模型，检查跨站切换、共享材质隔离、商业归属覆盖、总览恢复及连廊静止时的灰化更新；大丸连接回归检查覆盖 `platform`／`south-deck` 两个 2F 入口和 0／0.48／1 展开状态的视线射线。
