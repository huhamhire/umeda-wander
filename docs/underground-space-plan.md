# 地下公共空间与车站外围约束

## 表达方式

地下公共空间与二层天桥分开维护。天桥保留沿中心线生成桥面的方式；地下采用连续的平面区域，可以有渐变宽度、扩宽路口、弧形边界及包围建筑区块的孔洞。连接骨架描述相邻关系和接口，不等同于最终楼板，也不直接作为现场导航路线。

本图采用以车站为重点的示意比例。车站内部可以适当放大，商业占位与连接距离可以压缩；不要求所有区域统一米制缩放。调整时优先保留站点相对方位、线路方向、公共／付费边界、接入口顺序和步行连通关系。不能为对齐外部轮廓而单独拖动站内扶梯、直梯或站台。

## 数据分工

- `StationMap.site` 可由单个车站模块独立提供分层外围区域。未提供时，`describeStationSite` 从本站楼板、站台范围生成外围集合与付费范围；它不是把整个站画成一个包围矩形，也不是现场开挖边界。修改站内布局后，派生范围同步更新。
- `stationPublicPortal` 沿外部连接方向找到本站公共区域边缘。原本落在公共区中心的骨架端点会收至边界；已重叠的公共落台不向外反向延长。商业接口仍使用建筑轮廓上的接入口。
- `southern-underground.ts` 汇集南侧参考平面、分段宽度、路口区域和建筑占位。外围范围用于限制外部公共面，站内仍由各站模块绘制。
- `planUndergroundSpace` 合并可变宽度断面与面状节点，再减去占用区；保留所得多边形的孔洞。后续有清晰边界的资料可以直接增加区域轮廓，不必先拆成等宽通路。
- `PublicPassage.surfaceId` 表示已有公共面负责显示，原连线仅作为连接骨架保留。渲染时不再为这些骨架叠加长条楼板；围墙避让也以公共面为准。

同层商业地下楼板让出公共区域的真实多边形；相邻建筑占位则作为外部通路的避让范围。孔洞不会被重新填成楼板，地下也不添加天桥栏杆。公共面继续使用较深暖米色，区别于站台、付费区和商业区。

## 本次校准范围

以 `references/梅田周边地区通道.pdf` 和 `references/Umeda Walkway Maps/umeda-elevated-walkways-2026.pdf` 的地下图为依据，先处理阪神、西梅田、北新地、东梅田之间的 DIAMOR／Whity 网络，包括第一生命弧形互通、圆形节点、中央与斜向街区路口及沿线建筑接口。

参考平面沿用 `projectSouthReference`。既有站点的放大和显示偏移继续保留，本次没有把所有车站强制压到同一比例。分段宽度、节点折点仍是人工简化与显示拟合，不声称逐点描摹了工程开挖线。商业地下公共通路可进入同层商业楼板范围；楼板为通路让位，不代表绘制了完整商场室内图。

北侧 LUCUA／Yodobashi／梅北地下部分尚未转换成该连续面，二层天桥也不套用地下生成规则。后续按同一顺序扩展：核对参考连接骨架和面边界 → 校准车站重点区域及外围范围 → 安置建筑占位 → 对齐公共接入口 → 检查占位避让与连通性。避免在没有资料支持时用最短直线自动补接两个区域。

## 检查

新增测试覆盖渐变断面、区域并合与保留孔洞、站点独立边界、边缘接口、公共面与站体不重叠、骨架连续覆盖，以及商业楼板不覆盖公共面。另以离线平面图检查南侧组合，没有操作浏览器。
