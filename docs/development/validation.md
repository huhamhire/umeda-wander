# 验证与交付

## 基本检查

在仓库根目录运行，Node.js 24 或以上。Windows PowerShell 如限制 npm 脚本，使用 `npm.cmd`。

日常迭代优先运行 `npm run check:style:changed`。提交前或 CI 如需覆盖全仓库，使用 `npm run check:style`。

```powershell
npm run check:style
npm run typecheck
npm test
npm run build
git diff --check
```

按改动运行相关检查，提交前复核暂存差异；不为已通过且未变化的代码反复运行同一套检查。文档修改检查本地链接、路径、命令和事实引用；只调整链接与源码注释时无需重建模型或把历史测试数更新成当前数。

测试按[七个领域](../../tests/README.md)组织，`npm test` 递归收集全部 `*.test.ts`。单域可用 `node --test "tests/stations/*.test.ts"`；固定设施基线不可自动重写。公共空间的回归按地面、地下和高架分别定位。

## 数据与模型改动

| 改动 | 必须一并复核 |
| --- | --- |
| 本站布局、包络或站台 | 设备端点、平台归属、孔洞、围栏、路线节点、设施目录、轨道接头、公共接口 |
| 地下投影与道路配准 | 重新投影地下占位、重建地面范围；检查孔洞、付费区、公共面并集及接口共面 |
| 二层桥面或建筑入口 | 共享桥面所有者、楼板避让、栏杆留口、回廊、商业开口及目的地落脚 |
| 建筑体量与模型 | 承接关系、立面裁口、选层隐藏、路网开关、完整取景及许可记录 |
| 原始资料路径或版本 | catalog 哈希、来源用途、派生配置、受影响脚本和授权边界 |

按[地理脚本清单](../../scripts/geography/README.md#离线核查)选择站模、地下、二层或建筑的核查命令，数据重建顺序见[地理数据说明](../../data/geography/README.md)。产物写入忽略的 `build/`，网页由构建写入 `dist/`，均不直接维护或提交。

原始资料校验使用 `node scripts/geography/audit-references.ts`。哈希一致只证明本地版本未变化，不证明授权或外部网址仍可访问。

## 真实交互与交付边界

首次加载先显示可操作的导览面板。加载图标旁的一行文字随地图初始化更新。窄屏时这行提示位于底部导航面板上方。地图首帧完成后关闭提示，初始化异常时显示已有错误提示。

设施页在“全部车站”时需要输入关键词才显示候选，楼层和分类仍可缩小搜索范围。验收时覆盖中文与日文输入法组字、确认和清空，以及地图标签从筛选状态切到单项定位再恢复的过程。

步行路线页聚焦路线点输入框和生成预览时，保持当时的镜头中心、角度和缩放。候选楼层显隐和预览所需的楼层展开继续跟随导航状态。

视图分享验收时，拖动、旋转、缩放和切层后确认地址在变化停止时更新，并将地址复制到新标签页，核对镜头、选中设施及展开层级。写回链接时保留语言参数、其他查询参数和片段。未知设施或楼层回退为当前数据可用的状态。重新打开已预览路线时按已选地点顺序重新寻路。

右上角的「自由探索」按钮启动自动导览，默认显示圆点，导览中换成箭头。手机端显示同一按钮的图标。导览从带建筑外观的总览开始，一边逆时针旋转，一边拉近至可容纳 JR 大阪站站体、站台和大屋顶的取景范围。转到 JR 大阪站正西侧时淡出建筑外观和地面底图，以 3F 南北联络桥为取景重点，一边继续向西偏北转动，一边将 JR 全部楼层展开至 120%，再边旋转边移向梅北，到位后渐隐上层并切到 B1。环绕梅北站厅和地下站台后，转回 JR 地面站体时同步移动镜头和恢复楼层。拉近 3F 联络桥时保持缓慢旋转，随后展示 1F 中央通道。离开 JR 前往阪急时恢复地面底图。之后依序展示阪急站台、御堂筋线梅田、东梅田、阪神站厅及站台、西梅田和北新地，再拉远回到地区总览，沿同一旋转方向接入下一轮开场。阪神站用一次连续的侧向转动展示站厅与站台，转动中切层。车站特写的楼层展开幅度为 120%，细节镜头采用 25° 俯角，地下站沿站台侧面取景。站间先拉远，再带旋转转场。地下站之间保持地下剖切，回到地区总览时恢复地面。旋转轨迹贯穿各段和停留。镜头改变方向时平滑减速，楼层渐隐和渐显可与位移、旋转或变焦重叠。车站段沿用手动聚焦的楼层剖切及周边灰化规则，建筑外观在地区总览中显示。车站特写环绕时，已显示的标签每帧跟随镜头，遮挡和重叠约每 80 ms 刷新，切站、切层或画布尺寸改变时立即复核。转场和楼层渐变期间隐藏普通地图标签。独立说明卡随导览章节切换，窄屏位于顶栏下方，退出导览时隐藏。导览展开逐帧更新扶梯与楼梯的踏步、扶手和落台，整体缩放预览只用于手动拖动展开滑块。再次按按钮或 Esc 恢复原来的探索设置，拖动或缩放地图则接管当前镜头。开启减少动态效果时以静止画面推进。

自动导览通过 `tour=1` 分享。打开该链接后从总览重播。动画镜头不写回分享地址，退出时只移除导览参数。

平移、旋转、双指俯仰、捏合、镜头缓动和分层展开动画期间，近景和远景均隐藏浮动标签，画面停稳后恢复。从画布不同位置按中键拖动时，检查画布中心投影到 1F 平面的点和取景跨度保持固定。检查地图空白处的张手光标、平移中的握手光标和按下中键后的四向光标。悬停在可选设施或路线标记时，光标指示可点击。

使用电脑触控板时，检查 Alt／Option 加双指滑动的横向旋转、纵向俯仰、画布中心轴心及停稳后的标签恢复。另检查原有双指捏合缩放。

普通滚轮连续缩放时，检查浮动标签在滚动期间隐藏，并在最后一次有效滚轮事件约 140 毫秒后恢复。

点击地图工具栏的放大、缩小及恢复默认按钮，检查镜头平滑过渡。连续点击时从当时画面继续，恢复默认时取景中心、缩放、朝向和俯仰同步复位。拖动或滚轮可从动画中途接管镜头。开启减少动态效果时按钮直接应用目标取景。

触屏双指旋转和俯仰时，从画布中心外侧开始手势，检查画布中心投影到 1F 平面的点保持固定。分别在地面隐藏、楼层展开和中心被高架楼板覆盖时检查这一点。双指捏合从触点中点缩放。

在地图上按住 Shift 转动滚轮，检查楼层展开滑块同步、到达两端时停止、停止滚动后恢复标签，以及松开 Shift 后滚轮仍可缩放。

在 3F 拉满楼层展开并压低俯仰，检查滚轮或「−」仍能缩小较宽的视图，反向操作能放大。设施页在「全部车站」时点选某站设施，再次选择「全部车站」应解除车站聚焦。

手机端检查右上角全屏按钮。进入后默认收起导航面板，通过「地图操作」可重新展开。全屏时检查地图手势、设施点选、步行路线、语言和主题切换。横竖屏切换后仍能通过同一按钮退出，恢复进入前的导航展开状态。浏览器拒绝原生全屏时，地图在页面视口内进入沉浸模式。通过系统手势退出原生全屏时，页面需要同步恢复。

集成方可直接生成或编辑查询参数。例如 `?x=694&y=32&z=351&yaw=45&pitch=62&span=342&buildings=0`。默认的显示设置省略。链接可携带选中的设施及已预览路线，面板、筛选条件和路线草稿属于本地操作状态。

| 参数名 | 用途 |
| --- | --- |
| `x`、`y`、`z`、`yaw`、`pitch`、`span` | 必填镜头参数。坐标与纵向取景跨度使用场景米制单位，旋转和俯仰用度。有效俯仰为高于地图平面 5° 至 80°，与手势范围一致。 |
| `level`、`station`、`facility`、`explode` | 可选，分别指定楼层、聚焦车站、选中设施和展开量。 |
| `buildings`、`ground` | 建筑与地面开关。用 `0` 关闭、`1` 开启，默认开启。 |
| `sound` | 地图声音开关。用 `0` 静音、`1` 开启，默认开启。浏览器限制自动播放时，以点击、触摸或按键解锁。 |
| `stop`、`allow-paid` | 按出发、途经、到达顺序重复传入 `stop`。默认允许经过改札，用 `allow-paid=0` 避开改札。 |

按用户约定不直接操作浏览器。UI 变更仍需由用户在桌面及手机检查：资源加载、标签遮挡、选层与展开、导航面板、可见区聚焦、缩放／旋转及焦点恢复。离线几何、CPU 网格预览和替身测试不能替代 WebGL、性能、触控或现场通行验收。

交付说明写清改动、依据、实际运行的检查及剩余限制；未经明确要求不提交或推送。测试数量与性能数字是某次检查的快照，不作为长期门槛。
