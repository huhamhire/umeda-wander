## 共用原则

- 地面、建筑与站体共用米制基准，保持大致比例；设备可为可读性适当放大。现役配置中的标高、宽度和曲率仍含展示拟合，不冒充测量。
- 1F 为完整遮盖与路网，独立显隐；JR 中央通道属于地上 1F，不补地下捷径。
- B1 公共网共面；局部高差可保留 offset。探索分组相同不等于真实层高一致或付费区互通。
- 南北两组高架标高同归 2F；地下异形开挖面不能按高架等宽桥段简化。
- 几何接触、连通报告和相邻轮廓不能证明门洞、无障碍或可通行路线。
- 资料事实、人工拟合与待确认项分开。后续功能改进见 [Roadmap](../roadmap.md)。
