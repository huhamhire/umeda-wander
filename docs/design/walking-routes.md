# 步行路线

## 使用方式

- 「设施」页先显示查找。选中已接入步行图或有附近接入点的设施后，可以将它设为起点、终点，或加入已有路线草稿的途经点。
- 「步行路线」独立保存起点、终点和最多三个途经点。地点组右侧的「＋」添加途经点，可抓住每行左侧手柄拖动排序，首尾位置分别为起点和终点。切换到「楼层」可以查看当前层上的路线段，返回后继续编辑。
- 起点、终点和途经点各占一行，可直接输入关键词。选中设施后，地点框内显示对应图标，右侧的 × 可清除必选地点或移除途经点。下方快捷区提供车站筛选和地图选点，楼层和设施类型放在「更多选项」。底部同一行依次放置「允许经过改札」开关、清除路线的垃圾桶图标和「预览路线」。
- 选定车站后，列表显示站内设施及额外的步行图端点。未直接接入的设施会标明是否可导航至附近接入点。每一项都可以填入地点框，有精确或附近接入点的行程才可以预览。未指定车站时，输入关键词才显示搜索结果，筛选与设施页独立。
- 点击车站下拉框右侧的定位图标进入地图选点，按钮高亮，再点一次可取消。点按当前筛选范围内的设施模型或地点标签，直接填入当前编辑框并退出选点。

## 路径和范围

现役界面提供七站已有站内路线、南侧 B1 公共通道及 JR 大阪站往阪急的 2F 接驳**示意预览**。设施落点通过 [端点表](../../src/infrastructure/district/walking-places.ts) 显式绑定到既有图节点。改札目的地可落在闸外，穿过改札仍须通过对应闸机边。部分站厅或站台到达点没有对应设施条目，仍可从地点选择器或地图选取。

设施没有精确节点时，[附近接入点筛选](../../src/application/navigation/walking-approaches.ts)检查同一站点楼层、局部标高、闸区和连续可步行面，排除孔洞、商业和服务空间等阻隔。候选限于地图上 50 米内、已有名称且连入步行图的节点。预览在符合改札选项、通行方向和途经点顺序的完整路线中，优先选择各接入点距原设施总距离最短的方案。地点框保留设施名，预览逐项标明实际接入点。路线只绘制既有步行图上的路径。

| 闸外段 | 接入位置与依据 |
| --- | --- |
| JR 大阪站 ↔ 阪神大阪梅田 | 从 JR 中央口外经中央通路南端 68 号楼梯到 Crost B1，再沿地下公共通廊接阪神西口外。楼梯依据 [JR 大阪站构内图](../../references/stations/jr-osaka/station-guide.pdf)，B1 转折从[梅田地下通道图](https://www.city.osaka.lg.jp/toshikeikaku/cmsfiles/contents/0000369/369380/umeda05-3%28202607%29.pdf)及现役公共面拟合。 |
| 阪神大阪梅田 ↔ 西梅田 | 从阪神西口外沿地下通道进入西梅田北侧公共站厅。两侧的连接关系见[阪神构内图](../../references/stations/hanshin-umeda/station-guide.pdf)、[西梅田构内图](../../references/stations/nishi-umeda/station-guide.pdf)和[大阪市地下路线图](https://www.city.osaka.lg.jp/toshikeikaku/cmsfiles/contents/0000369/369380/umeda05-2%28202606%29.pdf)。 |
| 西梅田 ↔ JR 北新地 | 经西梅田站厅东侧公共通路到南改札附近，再往东接 JR 北新地西改札外。南端有小坡道，示意数据沿用 B1 公共面标高。见[大阪市换乘图 G](https://www.city.osaka.lg.jp/toshikeikaku/cmsfiles/contents/0000369/369380/umeda01-5-3%28202109%29.pdf)及[步行指引照片](https://www.city.osaka.lg.jp/shimin/page/0000621502.html)。 |
| JR 大阪站 → 阪急大阪梅田 | 从中央通路经北中庭 48 号扶梯上到 2F，沿 LUCUA 外侧、钟楼广场和连桥到阪急 2F 闸外。北中庭扶梯当前登记上行，桥面转折沿已建模公共面拟合。跨站关系见[大阪站城 2F 图](../../references/connections/osaka-station-city/2f-map.png)及[铁路间通行图](https://osakastationcity.com/pdf/hitoyasa_guide.pdf)。 |

南侧四站之间可双向规划闸外路线，也可从这些站接续前往阪急。西梅田北、中、南改札外均可设为起点、终点或途经点。纯 B1 换乘预览直接切到 B1，跨层换乘使用分层总览。

路线按用户给出的顺序逐段寻路。默认允许经过改札，仍遵守图中的可行方向。手动关闭后，若某段必须过闸，结果下会提供「允许经过改札并重试」。任何一段没有完整路径时，界面指出该段并清除路线图。预览使用展示坐标和已有示意边，未提供现场定位、动态通行状态或无障碍路线承诺。

楼板、通道轮廓、护栏留口和 `PassageGuide` 描述空间关系。可走的邻接关系由独立步行图确认。单站图和区际空间可以独立更新，接口对齐后仍需核对实体门洞、楼层高差、闸内外及通行方向。

## 维护入口

- `application/navigation/walking-route.ts` 复用领域寻路，处理有序途经点和首个不可达分段。
- `infrastructure/district/walking-places.ts` 维护可选端点及闸内外标记。新设施加入前核对同层落点与真实图节点，设施编号独立维护。
- `infrastructure/public-areas/south-diamor/walking-routes.ts` 明确登记跨站通道、转折点和两端的站内图节点。离线回归检查平走段位于对应的公共面内，跨层段连接 68 号楼梯的两端。实际通行宽度和转折位置仍以现场为准。
- `infrastructure/public-areas/north-decks/walking-routes.ts` 登记北中庭 1F 到 2F、北侧连廊和阪急闸外接段。测试覆盖公共楼板、井口和「北新地 → 阪神西口 → 阪急京都线」的完整预览。
- `presentation/components/walking-route-panel.ts` 管理路线草稿、筛选和确认。地图只拾取显式提供的节点，`RouteModel` 绘制当前路线。

其余跨站路径、任意落点约束与真机验收见 [Roadmap](../roadmap.md#步行路线)。验证命令见[开发验证规范](../development/validation.md)。
