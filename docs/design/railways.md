# 轨道走向与短段并线

## 依据与表达范围

轨道用于说明站台外的大致线路方向，不是道岔配线、允许进路或真实运行图。以校准后的站台端点和外围行车区域为基础，结合已提供地图及卫星图的方位关系；OSM 仅作宽泛方向参考，不能强行吸附导致直角或明显 S 弯。

| 区域 | 当前设计约束 |
| --- | --- |
| JR 地面 | 本线东西端均向偏北收转；东侧环状线与本线分别收束，避让阪急与百货，不互相穿插；西侧体现逐步靠拢 |
| 梅北 | 继承地下站台缓弧和斜交轴线，两端各由四股逐步收为双线；北端向 Grand Front 西侧道路地下收转 |
| 阪急 | 京都、宝冢、神户三组各自收为双线北行，不画站口远距离三岔；尾端只标线路 |
| M16／T20 | 从本站站台端逐步过渡为运行线，沿道路大致方向转弯；地下与地上外部铁路允许投影交叉 |
| Y11 | 北端尽头，仅南侧延伸 |
| 北新地 | 东西两端延伸，JR 东西线在四桥线下方通过；展示高差不解释为实测净空 |

## 维护入口

当前生成在 `src/infrastructure/geography/runtime-rails.ts`，JR 约束在 `stations/jr-osaka/rail-corridors.ts`，共用 `RailApproach` 领域图与 `presentation/models/stations/rail-approach-model.ts`。站台轨道和延伸线共用 `platformRail` 端点，合流节点共用切向，公共尾段只绘制一次。轨道不进入步行 `RouteEdge`。

站台及站外轨道的枕木以约 1.8 米展示间距均布，各段端点留半个间距，接头保持连续节奏。枕木使用实例化网格。

东侧按用户提供的卫星照片核对阪急站南沿、阪急百货北沿及 HEP 北侧的行车区域。站台先延续出站轴向，沿较长的缓变段逐步并为六股运行线（本线四股、环状线两股），再向东继续延伸；不设置横向收束点后再转回的折返曲线。运行线间距与并线位置为人工拟合，不表示核验了实际道岔。净距回归使用运行时道床、阪急全部站厅楼板及实际建筑外壳，不再仅用原始 OSM 线位检查避让。站模侵入现有建筑时先修订站体包络，不能削改已对齐的建筑轮廓。

西侧 11 番线接头曾被 Inogate 同高占位盖住。二层占位现在同时避让站台钢轨和延伸道床，不能通过重复补画轨道掩盖遮挡。`railApproachFootprints` 提供共用道床边界。

OSM 原始对象及许可见[轨道数据说明](../../data/geography/railways/README.md)；当前处理不能将示意合流映射当成各番线实际列车方向。地理延伸长度、转弯半径及束间距仍为展示拟合，实际乘车以站内标识为准。

## 环状线列车动画

JR 大阪站使用程序绘制的 223 系示意模型，按 4＋4 共 8 节编组。银色车体、蓝色腰带和中央贯通门参考 223 系车辆资料。车头的弧形肩部、大窗比例和低位灯组使用程序几何拟合。列车从地图首帧后第 3 秒开始自西向东驶入，每 60 秒重复，约 18 秒后在 2 号站台停车。停留 12 秒后起步，再用约 18 秒从东侧驶离。编组、速度和停靠都是地图演示参数。[JR 西日本车种资料](https://www.westjr.co.jp/company/info/issue/data/pdf/data2024_15.pdf) · [JR 西日本车辆照片](https://www.westjr.co.jp/press/article/items/171215_00_keihanshin_1.pdf)

`application/exploration/osaka-loop-train.ts` 依次采样西侧环状线接头、2 号股道及东侧延伸，按里程给各车厢定位。列车随所属站台层一起显隐和展开。减少动态效果时显示静止停靠画面，停靠和待发期间没有逐帧重绘。

镜头静止且只有列车运动时，复用上次取景和地图标签，只更新车厢并绘制场景。列车离开取景范围后改为低频检查，完全裁掉的车厢跳过矩阵更新和绘制。镜头、楼层或标签状态改变时优先走普通渲染流程。

## 验证

修改站体、站台长度或曲线时检查接头切向、局部转角、共用尾段、交叉、并线趋势、建筑道床净距及取景包络。相关回归位于 `tests/geography/`，离线对照由 `node scripts/geography/render-rail-merges.ts` 生成。北新地与 Y11 另检查轨道上下关系，不能为消除平面交叉移走真实下穿。
