# 轨道走向与短段并线

## 依据与表达范围

轨道用于说明站台外的大致线路方向，不是道岔配线、允许进路或真实运行图。以校准后的站台端点和外围行车区域为基础，结合已提供地图及卫星图的方位关系；OSM 仅作宽泛方向参考，不能强行吸附导致直角或明显 S 弯。

| 区域 | 当前设计约束 |
| --- | --- |
| JR 地面 | 本线东西端均向偏北收转；东侧环状线与本线分别收束，避让阪急与百货，不互相穿插；西侧体现逐步靠拢 |
| 梅北 | 继承地下站台缓弧和斜交轴线，两端各由四股逐步收为双线；北端向 Grand Front 西侧道路地下收转 |
| 阪急 | 京都、宝冢、神户三组各自收为双线北行，不画站口远距离三岔；尾端只标线路 |
| M16／T20 | 从本站站台端逐步过渡为运行线，沿道路大致方向转弯；地下与地上外部铁路允许投影交叉 |
| Y11 | 北端尽头，仅南侧延伸 |
| 北新地 | 东西两端延伸，JR 东西线在四桥线下方通过；展示高差不解释为实测净空 |

## 维护入口

当前生成在 `src/infrastructure/geography/runtime-rails.ts`，JR 约束在 `stations/jr-osaka/rail-corridors.ts`，共用 `RailApproach` 领域图与 `presentation/rail-approach-model.ts`。站台轨道和延伸线共用 `platformRail` 端点，合流节点共用切向，公共尾段只绘制一次。轨道不进入步行 `RouteEdge`。

OSM 原始对象及许可见[轨道数据说明](../../data/geography/railways/README.md)；当前处理不能将示意合流映射当成各番线实际列车方向。地理延伸长度、转弯半径及束间距仍为展示拟合，实际乘车以站内标识为准。

## 验证

修改站体、站台长度或曲线时检查接头切向、局部转角、共用尾段、交叉、并线趋势、建筑道床净距及取景包络。相关回归位于 `tests/geography/`，离线对照由 `node scripts/geography/render-rail-merges.ts` 生成。北新地与 Y11 另检查轨道上下关系，不能为消除平面交叉移走真实下穿。
