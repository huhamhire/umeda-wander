# 梅田地图维护 Roadmap

七站地理模型、地下公共网和主要二层连廊进入日常维护。这里记录资料补证、模型细化和人工验收事项。目录结构见[项目 README](../README.md#项目结构)，区域依据见[设计文档索引](./README.md)。

## 空间待核对

- **地下门位**：依据平面资料确定 JP 下沉广场到 Garden Avenue 主网，以及 E-ma、Hilton West 的具体门洞。核对北新地南侧出口、西梅田短升降落台与公共网的连接及高差。[南侧区域](./design/areas/south.md)
- **地下占位**：核对第一酒店等未登记街区的独立边界，保留源图公共开挖面及孔洞。[地下公共网](./design/public-areas/underground.md)
- **二层接口**：复核阪急西侧公共前沿、连廊宽度与净空、商业门位、设备落点及 Inogate 连桥两端的实际标高。[北侧区域](./design/areas/north.md) · [二层连廊](./design/public-areas/elevated.md)
- **公共直梯地下接驳**：核对 JR 北中庭 B 直梯（大阪市图编号 26）和阪神南出口直梯的 B1 门前落台如何接入公共主网。[二层连廊](./design/public-areas/elevated.md)
- **JR 北中庭**：核对时空广场 5F 的北侧扶梯落台边界、局部净高与广场其余公共范围。[JR 大阪站](./design/stations/jr-osaka.md)
- **外围地标候选**：评估蓝天大厦的模型范围与距离对取景的影响。

## 步行路线

- 扩展南侧 B1 路线到东梅田及御堂筋线，核对阪急往 JR 大阪站的反向跨层接入。分别记录站厅出口、公共通道、楼层、闸内外和通行方向，再将已确认的连接加入步行图。
- 扩展到通道内任意落点时，在当前物理楼层和同一可通行面内连接步行骨架；保留孔洞、围墙和改札隔断，对无法接入的位置给出反馈。
- 桌面和手机验收路线页地点筛选、地图选点回填、三个途经点的顺序调整、切层后继续编辑，以及遮挡下的标记可见性。

当前范围和端点维护见[步行路线设计](./design/walking-routes.md)。

## 人工验收

- 桌面浏览器检查总览与分层、遮挡、楼层聚焦、滑块、显示开关和设施定位。重点复核 JR 东侧轨道收束及阪神站务室周围楼板的可见性。[JR 大阪站](./design/stations/jr-osaka.md) · [阪神大阪梅田站](./design/stations/hanshin-umeda.md)
- 手机检查单指平移、双指张合缩放、扭转转向及同向上下拖动俯仰，确认同一次双指操作只触发一个动作，抬指后可切换。复核窄屏可读性，以及悬浮控件和安全区的避让。
- 桌面和手机检查次要设施标签仅在点选或定位后显示，并复核标签遮挡和取消定位后的状态。
- 分别用冷缓存和热缓存检查菜单先于立体画布可用、加载状态在首帧后消失，以及总览拖动时标签在松手后恢复。用浏览器性能记录区分地图初始化、模型提交和 GPU 绘制成本。

验证方式见[开发验证规范](./development/validation.md)。真实浏览器及手机验收由用户手动操作。
