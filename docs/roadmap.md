# 梅田地图维护 Roadmap

七站地理模型、地下公共网和主要二层连廊进入日常维护。这里记录后续功能改进。目录结构见[架构文档](./development/architecture.md#项目结构)，区域依据见[设计文档索引](./design/README.md)。

## 步行路线

- 补齐阪急往 JR 大阪站的反向跨层接入，将已有明确通行依据的设施接入导航网格。
- 扩展到通道内任意落点时，在当前物理楼层和同一可通行面内连接步行骨架；保留孔洞、围墙和改札隔断，对无法接入的位置给出反馈。

当前范围和端点维护见[步行路线设计](./design/walking-routes.md)。
