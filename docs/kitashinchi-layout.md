# JR 北新地站与西南地下公共连接

## 资料与结构

主要依据用户新增 `references/北新地.pdf` 第 1 页，图上日期为 2026-10-02；[JR 官方站图入口](https://eki.jr-odekake.net/premises?id=0612303)。地区关系采用 `references/梅田周边地区通道.pdf` 第 1 页，图上日期 2024-02。施工或临时扶梯停用按用户约定忽略。

北新地采用 B2 双线岛式站台、B1 东西改札及公共通路、地面出入口小型落台。1 番线京桥／四条畷／松井山手方向，2 番线尼崎／宝塚／三之宫方向。表达西侧及东侧的主要扶梯、站台电梯、地面电梯、绿色窗口、指定券售票机、站务室和图中 11-4、11-5、11-21、11-23、11-41 出口去向；局部坡道归并至公共层，临时设备状态不参与模型。

`kitashinchi-map.ts` 使用独立站点、独立 `kitashinchi-platform/hall/ground` 和 `Evidence.source: kitashinchi`，不能因同属 JR 就写成大阪站 PDF 页码。主要双排扶梯与逐条孔洞共用落点，设备进入既有菜单并追加 KS 编号。场景为主要布局示意，未逐一核验所有扶梯数量和开间。

## 地理与比例

近似站中心 `(34.6983222,135.4970361)` 用于地区投影；中心位置与西侧入口坐标不同，[MapFan 西侧定位](https://mapfan.com/spots/SCH%2CJ%2C0X0)也不能直接当成整站中心。根据地区图沿东西向取 88° 主轴，站台显示长 100、宽 7；这些是示意尺寸，不表示实测。南侧各站改用步行图的共同投影校准，取消独立向南 65、向东 12 单位的旧拟合；原始锚点和显示偏移分别保留，详见 `commercial-connections.md` 的南侧校准说明。

## 地区步行图的接入

`west-district-links.ts` 根据用户地下图补入以下公共连接：

1. 西梅田南侧公共区—北新地西侧联络口。
2. 阪神百货店口外—DIAMOR 大阪—北新地北侧公共入口。
3. 御堂筋线南改札外—DIAMOR 公共节点，与上一条共用实际几何端点。

这些连接共同表达地区步行拓扑，不展开第一至第四大楼及地下商场内部店铺；走线、宽度、局部坡道及展示标高为示意。只在资料确认的走廊方向上连接，不建立跨运营者 `RouteEdge`，不描述为已核验现场导航。Y11 北侧至阪神西口还使用两站各自的参考图，来源区分保留。

检查重点：东西改札的闸外接口、主要扶梯孔洞、直梯完整井道、所有落点支撑、公共走廊对付费区的全宽避让、七站菜单与聚焦、跨站层级及稳定镜头包络。浏览器及真机未操作。

## 轨道延伸与下穿

西、东两端轨道沿站台主轴继续，逐步收为间隔 4.4 场景单位的运行双线，共用 `platformRail` 端点与解析切向，不推断未提供的道岔。西梅田仅从南端延伸，北端仍保留车挡。

旅客站图的 B2 标识不是跨运营者的统一实测标高。[大林组施工记录](https://www.obayashi.co.jp/chronicle/works/d107.html)记载北新地结构为地下 2～5 层、开挖深度约 26.3～29.5m，不能据旅客图将其画成与四桥线同深。模型将北新地轨面层从 y=-16 降至 -24，表达 JR 东西线在四桥线下方通过；8 单位差为展示选择，不是资料核验的交叉净空。两者共用 stackIndex=-2，展开时保留高差；探索按钮仍合并 B2，不新增 B3。

站台扶梯的水平段随高度差加长，电梯井和上下开口同步；主要扶梯坡度约 32°，不因加深而变成近乎垂直。测试检查两条 JR 运行轨道与两条四桥线轨道的四个平面交点、三个展开状态的上下关系及 B2 分组。
