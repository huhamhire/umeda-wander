# 旧坐标总图退役

2026-11-17：已清除 `src/`、`tests/` 和 `scripts/` 对 `deprecated/` 的全部导入，删除旧总图的 22 个归档模块及旧坐标校准脚本，移除对应 TypeScript 包含项。需要历史对照时查 Git 版本 `b2a3da6`，不保留第二个可运行地图入口。

原来依赖归档的 29 个测试文件按用途处理，并非整批丢弃：

| 原检查范围 | 处理及现役覆盖 |
| --- | --- |
| 设施筛选、编号、镜头、切层、电梯完整性、大丸设备可见性 | 保留测试并改用 `district/geographic-map.ts`；编号接受独立公共设备 PUB，74 使用已核对的新组 ID |
| 七站局部设备、路线、闸机与来源 | 保留现役局部定义检查；组装、站点归属及共享层开口检查改用最终地理站模 |
| 车站模块纯组装 | 使用地理工厂及独立公共区域测试夹具，继续检查不变性、清单保留及重复 ID 拒绝 |
| 旧商业渲染器及独立缩放体量 | 删除 7 个旧图专属测试文件；现役实际模型由 `building-calibration`、`building-assembly-details`、`geographic-runtime` 与阶段四回归检查 |
| 手绘矩形连廊、旧 Whity 折线及地下占位 | 退役旧坐标常量断言；采用阶段三／四的源投影、公共分量、孔洞、付费区避让及占位检查 |
| 固定出口坐标与旧轨道 bundle 命名 | 移除旧参数断言；采用 `geographic-rail-continuity`、地理地下轨道及道床净距检查。真实轨道模型、并线接头和取景回归继续保留 |
| 旧版 OSM 下载对象 | 改查实际 H5 的 `geographicOsmData()`，继续验证许可、署名及未混入地下楼板／设施数据 |

设施基线独立冻结在 `tests/fixtures/legacy-facilities.json`，476 个旧候选、177 组跨层设备及七站站台均逐项追踪，不依赖归档代码生成，也不通过总数抵消遗漏。明确替代关系见 [设施迁移校对](./facility-migration-audit.md)。

`source-boundaries.test.ts` 现在同时检查源码、脚本及测试，防止重新导入已退役目录。七站现役局部布局仍参与地理模型生成，不能因为它们创建较早就随旧总图删除。

已核对的原始资料归到 [references](../references/README.md)，临时生成输出留在 `build/`。代码退役不删除参考资料或改写 Git 历史。

本批完成后，类型检查、197 项测试、构建、差异空白检查及 Git LFS 状态检查通过。设施清单审计为 511 个候选／195 组跨层设备，旧版逐项覆盖无缺项；22 份本地参考资料的路径、长度及 SHA-256 一致。离线图和几何检查不代替用户浏览器／手机验收。
